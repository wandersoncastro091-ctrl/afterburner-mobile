# Afterburner Mobile

Aplicativo Android nativo em Kotlin com painel de monitoramento inspirado no visual clássico do MSI Afterburner. Indicadores não expostos pelo Android aparecem como N/A; nenhum valor é inventado.

## APK
O GitHub Actions compila automaticamente o APK de depuração a cada push. Abra **Actions**, selecione a execução mais recente e baixe o artefato **AfterburnerMobile-debug-apk**.
